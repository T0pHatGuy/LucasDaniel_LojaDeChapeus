Tema: O tema deste projeto é uma "Loja de Chapéus", é um tema que eu escolhi por ter uma fascinação por chapéus e tive a decisão de criar uma loja com esse tema para o projeto. O objetivo deste projeto foi criar uma loja funcional de chapéus que utiliza os conteúdos aprendidos em aula.
Classes e pilares: Existem 6 classes dentro do código no total, cada classe com um objetivo próprio, a classe "Chapeu" é a classe mãe, ela é uma classe abstrata base que armazena o nome, cor e preco dos chapéus, ela possui um método abstrato calcular_preco() que é implementado pelas sub-classes, ela também exibe as informações pelo método exibir_informações(), as classes "Cartola" e "Fedora" são as sub-classes da classe mãe "Chapeu", ambas herdam os atributos da classe "Chapeu", além disso elas armazenam os atributos "tamanho" e "material", elas convertem material em Material caso informado como texto, ambas calculam o preço final adicionando o acréçimo do preço dos materiais usados, a classe "FabricaChapeu" é responsável pela criação dos objetos usando o método criar() que recebe todos os dados do chapéu e retorna "Cartola" ou "Fedora", caso o tipo não seja suportado é informado um erro, esta classe serve para o programa principal não precisar decidir qual classe instanciar, a classe "Cliente" guarda "nome" e "CPF" do usuário e representa aquele que está comprando os chapéus e gera uma representação textual usando __str__(). "Material" é uma enumeração que representa os materiais disponíveis para os chapéus e é o que define o acréscimo dependendo do material escolhido. Os pilares utilizados foram: Encapsulamento para os dados serem armazenados em atributos privados fazendo o acesso ser feito por propriedades, Abstração para a classe Chapeu definir o modelo geral dos chapéus sem representar um tipo específico e possui um método abstrato "calcular_preco" que obriga as sub-classes a fazerem suas próprias versões do cálculo, Herança para as sub-classes herdarem os atributos da classe mãe e o método "exibir_informacoes", Polimorfismo para os objetos serem tratados pela mesma referência "Chapeu" e executarem sua própria implementação de "calcular_preco()", outro conceito presente é a Enumeração que limita os materiais que podem ser usados.
Padrões de projeto: Para o código eu usei o padrado simple factory para criar a classe FabricaChapeu que se concentra na criação de objetos dependendo do tipo de chapéu informado, esse padrão evita que seja preciso conhecer os detalhes para a construção de cada classe no main.
Instruções: Para a execução do programa informe quantos chapéus deseja cadastrar na compra, depois use dados fictícios para seu nome e CPF, depois informe o programa o tipo de chapéu (cartola/fedora) que deseja,depois o modelo (qualquer modelo de cartola/fedora), adiante informe a cor, tamanho e material. Ao final do programa ele deverá exibir as informações do cliente e as informações dos chapéus que você cadastrou.
Funcionalidades: As funcionalidades do programa são para cadastrar o cliente, cadastrar 1 ou mais chapéus, escolher o tipo do chapéu, cadastrar os dados do chapéu, escolher o material dos chapéus, atribuir um preço inicial dependendo do tipo, calcular o preço final do chapéu com base nos materiais, validar as entradas que devem ser numéricas e não textuais e exibir os resultados.
